deprecated alias synced via setters so existing call sites keep
working without behavioral change.

  setters keep all three fields consistent

  bfs_skip / setter_sync) and setter behavior
- Replace 3 path.write() call sites with set_unity_root() so the
  deprecated alias stays in sync (cli_driver.rs:876 + 2x in
  commands/workspace.rs)

caller migration), P5 (frontend wiring + set_working_dir auto-resolve)
deferred. Frontend keeps calling set_working_dir unchanged; alias
